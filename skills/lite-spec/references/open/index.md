# /lite:open

用于为 AI 提供访问外部资料的能力，统一处理资料来源识别、访问方式判断、凭证检查与后续复用规则。

## 适用场景

- 用户给出 YApi、Swagger、OpenAPI、Figma、Axure、在线需求文档或其他外部链接
- 当前需求依赖外部资料，AI 需要先确认是否可访问
- 需要把“如何访问这些资料”沉淀成可复用规则，供 `/lite:plan` 等入口借用

## 默认流程

1. 识别资料来源与 URL 类型
2. 判断该资料是否公开可访问，还是需要登录 / token / cookie / header
3. 若来源属于 YApi、Figma、Swagger、原型系统或其他常见受限站点，直接读取 `references/open/credentials.md` 检查可复用凭证与持久化规则
4. 若用户本轮显式提供了可复用凭证，必须立即调用本地保存入口把凭证写入 runtime home；推荐使用 `scripts/save-credentials.ps1` 或 `scripts/save-credentials.sh`，不得只在当前会话内临时使用
5. 保存后必须立即调用 `scripts/show-credentials.ps1` 或 `scripts/show-credentials.sh` 验证 runtime home 中是否已存在对应凭证；不要手动读取并猜测字段结构
6. 对任意外部来源，必须再访问一个“机器可判定目标”确认登录、权限与目标可读性是否真实可用；不要只依据目标页面是否返回 HTML 做最终结论
7. 机器可判定目标优先级如下：
   - 来源的鉴权状态接口或当前用户信息接口
   - 目标资源的详情接口或元数据接口
   - 结构化 API 响应，例如 JSON、OpenAPI、Swagger、GraphQL introspection 结果
   - 若以上都不可用，再退回页面正文，但必须确认它不是登录页、首页或前端壳页面
8. 若来源属于 Axure / 原型系统，播放器页、壳页面或 `iframe about:blank` 不能直接作为“正文不可读”的结论；必须继续按 `references/open/prototype-systems.md` 里的专项规则解析导出资源、真实页面与图片结构
9. 若凭证缺失或失效，则进入阻塞状态并明确告知用户
10. 若资料可访问，则将可用访问能力交给 `/lite:plan` 或其他后续流程复用

## 阻塞判定

以下情况在“没有已保存凭证”或“机器可判定目标也失败”时，应判定为“资料当前不可访问”：

- 返回登录页
- 返回站点首页或通用壳页面，而不是目标资料正文
- 返回 401 / 403 / 需要登录
- 需要 cookie、token、uid、header 等会话信息但当前未提供

补充说明：

- 若 `show-credentials` 已显示存在已保存凭证，但目标 URL 仍只返回 HTML 壳页面，不可直接认定为“没有保存成功”或“凭证缺失”
- 此时应继续按“机器可判定目标优先级”做二次验证，再区分是页面类型问题、权限不足、凭证过期，还是目标资源本身不可读
- 换句话说，“页面 URL 只返回壳 HTML”本身不是最终结论；它只是提醒 AI 不能继续依赖页面正文，必须切到来源内更稳定的接口或结构化入口继续验证
- 对 Axure 这类原型导出尤其如此：外层播放器中的 `iframe about:blank` 经常只是运行时占位，真实页面通常仍可通过导出目录中的 `document.js` 与目标 html 页面解析得到；具体解析规则见 `references/open/prototype-systems.md`

一旦命中以上情况：

- 立即停止
- 明确说明缺少哪类凭证
- 不生成最终 `plan.md`、`tasks.md`
- 不继续代码实现
- 不基于猜测补全接口、页面行为、数据结构或任务细节
- 不把问题降级成普通“待确认问题”
- 回复中必须包含“如何获取凭证”的最短可执行步骤，不能只说“请提供凭证”

## 输出要求

- 明确说明资料是否可访问
- 明确说明使用了哪种访问方式
- 若用户本轮提供了凭证，明确说明“已保存到 runtime home，可供后续会话复用”
- 若受阻，明确指出缺少哪类凭证或会话信息
- 不把凭证写入仓库、计划文档、任务清单或最终说明

## 与 `/lite:plan` 的关系

- `/lite:plan` 遇到外部资料时，应先借用 `/lite:open` 的能力
- `/lite:plan` 不再单独维护一套凭证规则，而是复用这里的访问规则
- 若 `/lite:open` 判定资料不可访问，`/lite:plan` 应停在凭证阻塞状态，不生成最终 task，也不直接进入实现
